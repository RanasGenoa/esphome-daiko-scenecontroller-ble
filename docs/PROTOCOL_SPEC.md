# DAIKO シーンコントローラー (DP-41924) BLE Mesh プロトコル仕様書

本ドキュメントは、大光電機（DAIKO）製 6回路シーンコントローラー（型番: `DP-41924`）の Bluetooth Mesh 通信プロトコル、ベンダーモデル（Vendor Model）、メッセージ構造、Opcode、および送受信パケットフォーマットを整理した技術仕様書です。

---

## 1. ネットワーク & ノード構成

### 1.1 アドレス割り当て
| 用途 | アドレス | 形式 | 備考 |
|---|---|---|---|
| コントローラー（親機） | `0x0004` | Unicast Address | DP-41924 本体プライマリエレメント（Element数: 6） |
| 全体制御グループ | `0xC078` | Group Address | 主電源制御・シーン一括呼び出しグループ |
| ESP32（本コンポーネント） | `0x0020` (`0x0020`〜`0x002F`) | Unicast Address | ローカル Provisioner ノード（SeqNum上限時に自動+1巡回） |

### 1.2 ベンダーモデル (Vendor Model) & Opcode
- **Company ID (CID)**: `0x0AF8` (リトルエンディアン表記: `F8 0A`)
- **Vendor Model ID**: `0x0000`
- **3バイト Vendor Opcode 一覧**:
  | Opcode マクロ表現 | 16進表記 | 種別 | 主な用途 |
  |---|---|---|---|
  | `ESP_BLE_MESH_MODEL_OP_3(0xE1, 0x0AF8)` | `0xE10AF8` | **Vendor Get** | 状態・設定取得リクエスト（`0xE40AF8` で応答） |
  | `ESP_BLE_MESH_MODEL_OP_3(0xE2, 0x0AF8)` | `0xE20AF8` | **Vendor Set Ack** | 応答確認付き設定書き込み（シーン保存 `51 50`、時刻設定 `51 52`、スケジュール設定 `51 58`/`51 59`） |
  | `ESP_BLE_MESH_MODEL_OP_3(0xE3, 0x0AF8)` | `0xE30AF8` | **Vendor Set Unack** | 非確認制御コマンド（調光 `51 51`、回路開閉 `51 35`、主電源 `51 34`、シーン呼出 `02 08` 等） |
  | `ESP_BLE_MESH_MODEL_OP_3(0xE4, 0x0AF8)` | `0xE40AF8` | **Vendor Status** | 親機 `0x0004` からの状態・設定応答パケット |

## 2. パケット共通構造とサブコマンド一覧

### 2.1 シーンコントローラー専用フレーム (`0x51` ヘッダ)
シーン呼出以外のすべてのシーンコントローラー向けメッセージは、先頭に `0x51`、続いてサブコマンドと 16bit リトルエンディアンのペイロード長を持ちます。

```text
+----------+---------------+----------------+----------------+---------------------+
| Byte 0   | Byte 1        | Byte 2         | Byte 3         | Byte 4...           |
+----------+---------------+----------------+----------------+---------------------+
| 0x51     | Sub-Command   | Length (Low)   | Length (High)  | Payload Bytes...    |
+----------+---------------+----------------+----------------+---------------------+
```

### 2.2 全サブコマンド対応表
| ヘッダ + SubCmd | 名称 | 送信用 Opcode | 宛先 | ペイロード長 | 概要 |
|---|---|---|---|---|---|
| `51 01` | `CTRL_INFO` | `0xE10AF8` (Get) | `0x0004` | Req: `0` / Resp: `97` (計101B) | 親機全体設定・回路種別・RTC・全6シーン設定の一括取得 |
| `51 02` | `LEVEL_INFO` | `0xE10AF8` (Get) | `0x0004` | Req: `0` / Resp: `12` (計16B) | 全12チャンネルの現在レベルと回路別リレー開閉状態の取得 |
| `51 05` | `WEEKLY_SCHEDULE_GET` | `0xE10AF8` (Get) | `0x0004` | Req: `0` | 週間スケジュール設定の取得 |
| `51 06` | `TIME_INFO_GET` | `0xE10AF8` (Get) | `0x0004` | Req: `0` / Resp: `7` (計11B) | 親機内蔵 RTC 現在時刻の取得 |
| `51 08` | `DAILY_SCHEDULE_GET` | `0xE10AF8` (Get) | `0x0004` | Req: `1` (`index`) | 日別スケジュール設定の取得 |
| `51 10` | `INTERLOCK_INFO` | `0xE10AF8` (Get) | `0x0004` | Req: `0` / Resp: `7` (計11B) | センサー連動設定の取得（`0xFF` = 未設定） |
| `51 11` | `SETTING_STATUS` | `0xE10AF8` (Get) | `0x0004` | Req: `0` / Resp: `1` (計5B) | 本体パネル設定モード状態の取得（`3` = 本体設定中） |
| `51 33` | `CHANNEL_STEP` | `0xE30AF8` (Set Unack) | `0x0004` | `2` (`[ch, dir]`) | チャンネル段階調光・調色（27段階テーブルに従い UP/DOWN） |
| `51 34` | `MASTER_POWER` | `0xE30AF8` (Set Unack) | `0xC078` | `1` (`[on_off]`) | 主電源（マスター電源）一括 ON (`0x01`) / OFF (`0x00`) |
| `51 35` | `CIRCUIT_ONOFF` | `0xE30AF8` (Set Unack) | `0x0004` | `2` (`[circuit, on_off]`) | 回路別給電スイッチ（リレー）ON (`0x01`) / OFF (`0x00`) |
| `51 36` | `SCHEDULE_MODE` | `0xE30AF8` (Set Unack) | `0x0004` | `1` (`[mode]`) | タイマーモード切替（`0`=OFF, `1`=Daily, `2`=Weekly） |
| `51 37` | `CANCEL_SETTING_MODE` | `0xE30AF8` (Set Unack) | `0x0004` | `1` | 本体パネル設定モードの強制解除 |

| `51 51` | `CHANNEL_DIMMING` | `0xE30AF8` (Set Unack) | `0x0004` | `2` (`[ch, level]`) | チャンネル別（`0..11`）の調光率・調色率（`0..100%`）設定 |
| `51 52` | `TIME_INFO_SET` | `0xE20AF8` (Set Ack) | `0x0004` | `7` (`[YY,MM,DD,WW,hh,mm,ss]`) | 親機内蔵 RTC 現在時刻の書き込み（`YY` = 西暦下2桁） |
| `51 58` | `DAILY_SCHEDULE_SET` | `0xE20AF8` (Set Ack) | `0x0004` | 可変 | 日別タイマースケジュールの書き込み |
| `51 59` | `WEEKLY_SCHEDULE_SET` | `0xE20AF8` (Set Ack) | `0x0004` | 可変 | 週間タイマースケジュールの書き込み |
| `02 08` | `SCENE_RECALL` | `0xE30AF8` (Set Unack) | `0xC078` | 固定5B (`02 08 <s> 00 00`) | 登録シーン `0..5`（シーン1〜6）の一括呼び出し |

## 3. 制御コマンド詳細仕様

### 3.1 主電源（マスター電源）制御 (`51 34`)
各回路の調光・調色設定値を保持したまま、コントローラー全体の出力を一括制御します。
- **Opcode**: `0xE30AF8` (Set Unack)
- **宛先**: `0xC078` (Group)
- **フォーマット (5バイト)**:
  ```text
  51 34 01 00 <state>
  ```
  - `<state>`: `0x01` = 主電源 ON、`0x00` = 主電源 OFF

### 3.2 回路別 点灯状態（リレー）制御 (`51 35`)
各回路（回路1〜6）の回路スイッチ状態（`LevelInfo` の MSB `0x80` フラグ）を個別に制御します。
- **Opcode**: `0xE30AF8` (Set Unack)
- **宛先**: `0x0004` (Controller Unicast)
- **フォーマット (6バイト)**:
  ```text
  51 35 02 00 <circuit_idx> <state>
  ```
  - `<circuit_idx>`: `0x00`〜`0x05`（回路1〜6）
  - `<state>`: `0x01` = 点灯有効（ON）、`0x00` = 回路遮断（OFF: 下位7bitの調光率は保持したまま `0x80` ビットをセット）

### 3.3 チャンネル別 調光・調色レベル制御 (`51 51`)
6回路 × 2チャンネル = 計12チャンネルの明るさまたは色温度を `0`〜`100` (%) で直接指定します。
- **Opcode**: `0xE30AF8` (Set Unack)
- **宛先**: `0x0004` (Controller Unicast)
- **フォーマット (6バイト)**:
  ```text
  51 51 02 00 <channel_idx> <level>
  ```
  - `<channel_idx>`: `0x00`〜`0x0B`（0〜11）
    - **偶数チャンネル $(c - 1) \times 2 \in \{0, 2, 4, 6, 8, 10\}$**: 回路 $c$ の **明るさ（調光率）** または **ON/OFF出力**
    - **奇数チャンネル $(c - 1) \times 2 + 1 \in \{1, 3, 5, 7, 9, 11\}$**: 回路 $c$ の **色温度（調色率）**
  - `<level>`: `0x00` (0%) 〜 `0x64` (100%)
    - 調光回路 (`0x01`/`0x02`)・調光調色回路 (`0x06`): `0`〜`100`%
    - ON/OFFスイッチ回路 (`0x03`): `0x64` (`100`) = ON、`0x00` (`0`) = OFF
    - 色温度（奇数ch）: `0` = 電球色 (2700K / 370 mireds) 〜 `100` = 昼白色 (5000K / 200 mireds)
- **レート制限仕様**: スライダー連続操作時は **330ms** 周期で送信間隔を制御することで、BLE Mesh Advertising ベアラの輻輳および親機側の受信取りこぼしを防止します。

### 3.4 チャンネル段階ステップ制御 (`51 33`)
ボタン長押しやステップ操作で使用される段階調光コマンドです。
- **Opcode**: `0xE30AF8` (Set Unack)
- **宛先**: `0x0004`
- **フォーマット (6バイト)**:
  ```text
  51 33 02 00 <channel_idx> <direction>
  ```
  - `<channel_idx>`: `0x00`〜`0x0B`
  - `<direction>`: `0x00` = DOWN（暗くする/暖色へ）、`0x01` = UP（明るくする/寒色へ）
  - **ハードウェア 27段階ステップテーブル**:
    `[0, 3, 7, 11, 15, 19, 23, 27, 31, 35, 38, 42, 46, 50, 54, 58, 62, 65, 69, 73, 77, 81, 85, 89, 93, 97, 100]`

### 3.5 シーン呼び出し (`02 08`)
ライコン本体に登録されているシーン1〜6を呼び出します。
- **Opcode**: `0xE30AF8` (Set Unack)
- **宛先**: `0xC078` (Group)
- **フォーマット (5バイト)**:
  ```text
  02 08 <scene_idx> 00 00
  ```
  - `<scene_idx>`: `0x00`〜`0x05`（シーン1〜6に対応）

### 3.6 シーン設定保存 (`51 50`)
指定したシーンに全12チャンネルの目標レベルとフェード時間（秒）を保存します。
- **Opcode**: `0xE20AF8` (**Vendor Set Ack**)
- **宛先**: `0x0004` (Controller Unicast)
- **フォーマット (18バイト)**:
  ```text
  51 50 0E 00 <scene_idx> <ch0> <ch1> ... <ch11> <fade_sec>
  ```
  - `<scene_idx>`: `0x00`〜`0x05`（シーン1〜6）
  - `<ch0>..<ch11>`: 各チャンネルの設定値（`0`〜`100`、そのシーンで消灯させる回路の偶数chは `0xFF`）
  - `<fade_sec>`: フェード遷移時間（秒、例: `0x04` = 4秒）

### 3.7 内蔵 RTC 時刻設定 (`51 52`)
- **Opcode**: `0xE20AF8` (**Vendor Set Ack**)
- **宛先**: `0x0004`
- **フォーマット (11バイト)**:
  ```text
  51 52 07 00 <YY> <MM> <DD> <WW> <hh> <mm> <ss>
  ```
  - `<YY>`: 西暦年 - 2000（例: 2026年 = `0x1A`）
  - `<MM>`: 月（`1`〜`12`）
  - `<DD>`: 日（`1`〜`31`）
  - `<WW>`: 曜日（`0`〜`6`）
  - `<hh>`, `<mm>`, `<ss>`: 時・分・秒

## 4. 状態取得・応答パケット詳細仕様 (`0xE10AF8` -> `0xE40AF8`)

### 4.1 コントローラー全体設定 (`CtrlInfo`: `51 01`)
- **リクエスト (4バイト)**: `51 01 00 00`
- **レスポンス (101バイト / BLE Mesh 9セグメント転送)**:

| バイト範囲 | フィールド名 | 内容・デコード仕様 |
|---|---|---|
| `0..3` | Header | `51 01 61 00`（SubCmd=`0x01`, Payload Length=`0x0061` = 97 bytes） |
| `4` | `activeScene` | 現在選択されている（最後に呼び出された）シーン番号 (`0x00`〜`0x05` = シーン1〜6) |
| `5` | `powerMode` | **主電源状態**: `0x01` = ON、`0x00` = OFF |
| `6` | `scheduleMode` | **タイマーモード**: `0x00` = OFF、`0x01` = 日別 (Daily)、`0x02` = 週間 (Weekly) |
| `7` | `dailyScheduleIndex` | 選択中の日別スケジュール番号 |
| `8` | `weeklyScheduleMode` | 週間スケジュールサブモード |
| `9..14` | `circuitTypes[0..5]` | **回路1〜6のハードウェア負荷設定 (`L1`〜`L6`)**:<br/>- `0x01` (**L1**): LED調光タイプ（逆位相制御 -> `ColorMode::BRIGHTNESS`）<br/>- `0x02` (**L2**): 白熱灯調光タイプ（逆位相制御 -> `ColorMode::BRIGHTNESS`）<br/>- `0x03` (**L3**): ON/OFFタイプ（非調光 -> `ColorMode::ON_OFF`）<br/>- `0x04` (**L4**): PWM調光タイプ（PWM信号線式 -> `ColorMode::BRIGHTNESS`）<br/>- `0x05` (**L5**): PWM調色調光タイプ（PWM信号線式 -> `ColorMode::COLOR_TEMPERATURE`）<br/>- `0x06` (**L6**): 信号線不要調色調光タイプ（逆位相制御 -> `ColorMode::COLOR_TEMPERATURE`）<br/>※本コンポーネント（`type: auto`）はこのフィールドから各回路の照明種別を自動判別し、NVS（`daiko_ctype_v1`）へ永続化して Home Assistant の `light` エンティティ属性に自動反映します。 |
| `15` | Reserved | 予約領域 (`0x00`) |
| `16..22` | `timeInfo[0..6]` | 内蔵 RTC 現在時刻 `[YY, MM, DD, WW, hh, mm, ss]` |
| `23..100` | `scenes[0..5]` | **全6シーンの設定データ（13バイト × 6シーン = 78バイト）**:<br/>各シーン $s \in \{0..5\}$ の先頭オフセットは $23 + 13s$:<br/>- `offset + 0..11`: `ch0..ch11` の設定レベル (`0..100`、消灯設定回路の偶数chは `0xFF`)<br/>- `offset + 12`: `fadeTime`（フェード時間［秒］） |

### 4.2 各回路現在レベル (`LevelInfo`: `51 02`)
- **リクエスト (4バイト)**: `51 02 00 00`
- **レスポンス (16バイト / BLE Mesh 2セグメント転送)**:
  ```text
  51 02 0C 00 [C1_dim] [C1_col] [C2_dim] [C2_col] [C3_dim] [C3_col] [C4_dim] [C4_col] [C5_dim] [C5_col] [C6_dim] [C6_col]
  ```
  - 回路 $c \in \{1..6\}$ のデータオフセットは `dim_byte = data[4 + (c-1)*2]`, `col_byte = data[4 + (c-1)*2 + 1]`。
  - **`dim_byte` の二重状態エンコーディング**:
    - **Bit 7 (`0x80`)**: `51 35`（またはシーン内の `0xFF` 消灯指定）による **回路遮断フラグ**。
      - `0` (`dim_byte <= 100`): 回路スイッチ ON（通電有効）
      - `1` (`dim_byte >= 0x80`, すなわち `128 + level`): 回路スイッチ OFF（下位7bitに調光率 `level` を保持したまま消灯）
    - **Bits 0..6 (`dim_byte & 0x7F`)**: 保持または出力中の調光レベル（`0`〜`100`%）
  - **`col_byte`**: 色温度レベル（`0`〜`100`%）

### 4.3 内蔵 RTC 時刻応答 (`TimeInfo`: `51 06`)
- **リクエスト (4バイト)**: `51 06 00 00`
- **レスポンス (11バイト)**: `51 06 07 00 <YY> <MM> <DD> <WW> <hh> <mm> <ss>`

### 4.4 本体パネル設定モード状態 (`SettingStatus`: `51 11`)
- **リクエスト (4バイト)**: `51 11 00 00`
- **レスポンス (5バイト)**: `51 11 01 00 <status>`
- `<status> == 0x00`: 通常待機中
- `<status> == 0x03`: 壁面コントローラー本体パネルで設定操作中

## 5. プロビジョニング & 設定注入シーケンス

ESP32 は Bluetooth Mesh Provisioner ロールおよび Configuration Client ロールとして動作し、壁面コントローラー（`DP-41924`）の初期登録・設定注入（Provisioning & Configuration）を実行します。

### 5.1 プロビジョニング手順概要
1. **PB-ADV (Unprovisioned Beacon) 検出**:
   - `DP-41924` がペアリング解除状態（初期化／未プロビジョニング状態で、`通信ランプ（青色）` が等間隔に点滅）になると、未プロビジョニングビーコンを送出します。
   - ESP32 がビーコンを受信し、Device UUID と OOB 情報を取得します（`KEY_NO_OOB: true`）。
2. **ノードアドレス割り当て**:
   - ESP32 は `DP-41924` に対して Unicast アドレス `0x0004` を割り当てて PB-ADV プロビジョニングを実行します。
   - プロビジョニング完了後、ESP32 側の SeqNum は 2000、IV Index は 0、セルフアドレスは `0x0021` にリセットされます。
3. **AppKey Add (`ESP_BLE_MESH_MODEL_OP_APP_KEY_ADD`)**:
   - NetKey インデックス `0x000` に対して、設定された AppKey（Index: `0x000`）を送信・登録します。
4. **Model App Bind (`ESP_BLE_MESH_MODEL_OP_MODEL_APP_BIND`)**:
   - `DP-41924` のプライマリエレメント（`0x0004`）上の Vendor Model（Company ID: `0x0AF8`, Model ID: `0x0000`）に対して AppKey Index `0x000` をバインドします。
5. **Model Subscription Add (`ESP_BLE_MESH_MODEL_OP_MODEL_SUB_ADD`)**:
   - 同じ Vendor Model に対して、一括制御グループアドレス `0xC078` を購読グループ（Subscription List）として追加します。
6. **ステータス同期・回路種別自動判別**:
   - ベンダーコマンド `51 01` (`CtrlInfo`) および `51 02` (`LevelInfo`) を発行し、初期同期および回路種別の判別・永続化を行います。
